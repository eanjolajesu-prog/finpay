# FinPay 💳

### A modern FinTech payment platform exploring digital banking and payment experiences.

FinPay is a front-end FinTech portfolio project designed to explore modern digital payment interfaces and create a simple, intuitive financial experience.

The project focuses on clean UI design, responsive layouts, and interactive web experiences using fundamental front-end technologies.

> **Note:** FinPay is a personal portfolio project and is not a real payment service.

---

## 🚀 Features

Currently implemented:

- Responsive navigation bar
- Modern FinTech landing page
- Digital payment card interface
- Hero section with call-to-action buttons
- Features section
- Security section
- Responsive design

### 🔨 Coming Soon

- Interactive payment dashboard
- Send money functionality
- Transaction history
- Transaction search and filtering
- Dynamic account balance
- Payment validation
- Interactive JavaScript components
- Mobile navigation menu

- HTML5
- CSS3
- JavaScript
